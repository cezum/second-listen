# Demo 台词 —— 中文模拟 debrief（约 50 秒）

Project 8 是为本次演示设定的虚构被投企业。

> 与 [demo-script.md](demo-script.md) 的英文版同构：三个信号埋在闲聊里，
> 第一遍听着像普通汇报，agent 应该把三个都抓出来。

## 口述稿（照着读即可）

```text
嗯，快速复盘一下 Project 8。跟 Ben 的电话聊得挺顺利，气氛很轻松。
对了，他还提了句，新办公室装修快收尾了。三季度营收基本持平，
不过他不太担心，说企业客户那条线的 pipeline 能补上来。
哦，还有个事——Sarah，就是财务总监，上个月其实走了。
现在还在面接替的人，账暂时是 Ben 自己看着。
还有那个研发补助金，他们挪了一部分去发工资，说是临时周转，他说没事。
其他都挺好，下个月再约一次电话。
```

## 埋点对照表

| # | 埋的信号 | Playbook 维度 | 清单触发 |
|---|---|---|---|
| 1 | 财务总监离职，账由 Ben 临时看着，接替者未定 | 团队完整度 | 关键人员流失 / 核心岗位空缺 |
| 2 | 研发补助金挪去发工资 | 财务健康 | 资金未按约定用途使用 |
| 3 | 营收走平但管理层乐观 | 经营 | 追问信号 |

干扰项（不该被追着问的闲聊）：新办公室装修快收尾了。

## 预期追问

- “Sarah 走了之后财务谁在管，从什么时候开始？”
- “挪研发补助金，有没有书面审批？”
- 营收走平：问是否进了销售预测 / 具体差距多大。

## 试用提示

- 用自然语速读，像在跟同事闲聊，不用刻意强调信号。
- agent 中途打断追问是正常行为，被打断就停下来答它的问题。
- 你讲中文即可；agent 的回复大概率是英文（voice 配置为 anna），
  如果想让 agent 也讲中文，需要换支持中文的 voice 或调 LLM 语言，列为后续优化点。
