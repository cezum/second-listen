# Hackathon Demo Shot List

Use this checklist with [`hackathon-demo-script-2min.md`](hackathon-demo-script-2min.md).
The target is a clean, edited two-minute submission video, not an improvised
live presentation.

## Before recording

- Start from the blank workspace state.
- Confirm the company field and sample use `Project 8`.
- Confirm the sample banner says it is fictional and not a live AI result.
- Close developer tools, terminals, API dashboards, and unrelated browser tabs.
- Do not use real company names, real recordings, or real investment information.
- Keep the API key only in the server environment; never show it on screen.

## Capture pass A — real integration proof (15 seconds)

1. Enter `Project 8`.
2. Click `Start debrief`.
3. Say:

   > The balance sheet looks better than six months ago, but cash flow has not improved.

4. Wait for the agent to respond.
5. Show the live transcript and the focused follow-up question.
6. End the debrief before opening the sample.

Keep this clip short. Its purpose is to prove the real voice path; it does not
need to contain the full report.

## Capture pass B — complete product walkthrough (60–75 seconds)

1. Return to the blank workspace.
2. Click `Watch a sample`.
3. Let both voices play without narration over the dialogue.
4. Keep the left transcript and right report visible together.
5. Capture these moments:
   - the first sentence finishes before the finance risk appears;
   - the grant and revenue sentence finishes before the next findings appear;
   - the agreed action appears only after the investor accepts it;
   - the report shows quotes, review flags, and owner/deadline.
6. Stop after the sample says the follow-up has been recorded.

## Capture pass C — recording input proof (10–15 seconds)

1. Close the sample.
2. Enter `Project 8` again.
3. Upload a short fictional English recording, or use a prepared screen capture
   of a successful upload result.
4. Show the recording report on the right.
5. Briefly show the transcript, risk signals, source quotes, and download action.

The audio file is a temporary demo asset only. Do not add it to GitHub.

## Editing order

| Time | Clip | Purpose |
|---|---|---|
| 0:00–0:12 | Blank workspace + narration | Establish the investor problem |
| 0:12–0:20 | Project 8 entered | State that the case is fictional |
| 0:20–0:35 | Capture pass A | Prove the real voice integration |
| 0:35–1:35 | Capture pass B | Show the complete cause-and-effect workflow |
| 1:35–1:52 | Completed report | Explain evidence, review, and actions |
| 1:52–2:00 | Capture pass C + closing | Show the second input path |

## Fallback if live voice is unstable

Use a successful recording-upload result for the real integration proof, then
use the full labeled sample for the product story. Do not present the browser
speech sample as a live AI response.

## Final quality check

- The first risk never appears before its supporting sentence is spoken.
- The words `Project 8` and `fictional` are visible or spoken.
- The video includes a real live or upload result, not only the sample.
- No API key, real recording, local path, or private data appears.
- The final report clearly shows evidence quotes and a concrete follow-up.
